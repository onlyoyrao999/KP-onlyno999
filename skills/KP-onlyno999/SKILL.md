# KP-onlyno999：智能图鉴、角色设定、电商打版、美食食谱与简笔漫画制图

## Purpose

五模态智能制图：根据用户输入自动选模式，一次生成对应制图——
- **模式一 Lookbook**：电商服装四联打版图（大头照 / 正面全身 / 90°侧面 / 背面全身，1:1:1:1 分栏，默认 16:9 横版，影棚标准光＋鞋履锁死）。
- **模式二 Character Sheet**：角色概念设定集（三视图主立绘＋服装分层解构＋1x5 材质微距矩阵＋书法印章包装）。
- **模式三 Naturalist Infographic**：自然科学九宫格科普海报（双语标题＋分布地图＋主视觉插画＋01–09 信息卡＋青山底部）。
- **模式四 Recipe Infographic**：美食食谱信息图（默认 1:1 方形、手绘水彩美食插画风：左上标题区菜品小图标＋菜名＋副标 / 右上成菜 Hero 大特写盘边出血 / 左中食材矩阵 3 列手绘图标＋名称分量 / 下方 2×3 步骤流手绘插画＋序号徽章＋箭头 / 右下贴士卡；中文文字禁令——AI 只出骨架与素材，中文后期合成）。
- **模式五 Jianbi Manhua（简笔漫画）**：简笔漫画主角设计图（触发：用户丢一张图＋说「简笔漫画」即启动，不再追问。默认双出——①电影海报式：单幅电影级关键帧海报，低角度强张力、强氛围完成度；②角色动作设计式：同一角色多姿态动态动作设计（起势/腾空/出招/扫腿/收势），锁脸锁服装。点名「展板/解构」时另出③解构展板式：大主视觉 Hero＋右上对峙/环境板＋右中武器服饰拆解＋底部 01–04 细节网格。人物一律按「简笔动画主角法」重设计——母本为经典国产动画电影（简笔勾线、平涂色块、五官极简、衣纹概括，平涂人物压水墨背景），原图锁脸型体型与标志服装配色。总风格母本锁死「中国学派」老美术片（上美影黄金时代：平涂赛璐珞人物＋水墨写意背景两层分离、戏曲脸谱与鱼鳞云纹装饰、朱红对墨绿的民间浓色）。水墨定调：暗青/墨绿/水墨黑打底、米白留白、朱砂红跳色，赛璐珞手绘＋水墨飞白＋纸张颗粒）。

## Workflow

1. **判型**：看用户输入自动选模式，拿不准就问——
   - 服装单品 / 模特上身 / 穿搭打版 → 模式一，读 `references/lookbook_prompt.md`
   - 人物肖像 / 国风 / 二次元 / 仙侠武侠角色 → 模式二，读 `references/character_prompt.md`
   - 动植物 / 昆虫 / 自然主题或底图 → 模式三，读 `references/master_prompt.md`、`nine_modules.md`
   - 用户上传菜品照片（＋可选一句话备注）→ 模式四，读 `references/recipe_prompt.md`（通用流程：照片进 → 识菜填实 → 成品出）
   - 用户丢一张图（照片 / 视频截图 / 剧照）＋说「简笔漫画」→ 模式五，读 `references/jianbi_manhua_prompt.md`（通用流程：一图进 → 识图定势 → 主角化设计 → 成品出）
2. **组装内容**：按对应模式的提示词模板把占位符逐项填实；
   模式三的科学数据不确定先查证，不编造拉丁学名与数字；
   模式四先看图识菜再填实：菜名、副标、标题小图标、食材清单（带分量，目测估算）、6 个步骤与贴士条目——中文只进合成阶段，不进生成提示词；
   模式五先看图识势再填实：主体与服饰锚点、最具张力的动作瞬间（静态图取立像之势）、环境骨架、唯一跳色锚点、4 格细节网格候选，逐项提取后按展板式四区或单帧式色彩脚本组装；
   人物再按「简笔动画主角法」定式（见 references/jianbi_manhua_prompt.md）：简笔勾线、平涂色块、五官极简，保留原图脸型体型与标志服装配色，不套滤镜、不擅自换装。
3. **生成**：调用 `media.generate_image`，中文文字原样填入（模式四除外——见规则 8）；
   模式一/二输出到 `workspace/sheets/`，模式三/四/五输出到 `workspace/poster/`。
   模式五附用户原图做 `kind: image` 参考锁主体特征；默认双出电影海报式＋角色动作设计式各一张，用户点名「展板/解构」时加出解构展板式。
   模式四分两步走：① 并行生成 10 张（排版骨架 1、标题小图标 1、成菜 Hero 1、食材图标网格 1、步骤插画 6），一律手绘水彩风；
   Hero/图标/步骤附上传照片做 `kind: image` 参考，保证画的是这道菜；
   ② 在排版工具中按版面结构合成，填入真实中文（标题 / 副标 / 食材分量 / 步骤说明 / 贴士）。
4. **检查**：模式一看四栏人物/服装/影棚是否一致，第2/3/4栏脚踝未被裁切、鞋子完整落地；模式二看三视图面部服装是否一致；
   模式三核对大标题、模块序号与关键数据；模式四核对骨架四分结构是否正确、部件图是否齐全、画面无模型渲染的中文乱码，
   合成后逐字核对中文；模式五核对主体特征与原图一致（动作设计式逐姿态核对同一张脸、同一套服装）、展板式四区齐全、水墨定调（墨底/留白/跳色≤两处）与编号无错位。关键错误重绘，同一问题不超两次。
5. **交付**：成图以附件形式交付，并给出文件路径。

## Output Contract

- 制图成图（附件）＋ 存档路径
- 使用的完整填实提示词（用户要复用时给）

## Operating Rules

1. 模板中的中文文字原样填入提示词，不翻译、不省略、不改写。
2. Lookbook 四栏必须是同一模特、同一套服装、同一影棚参数，默认 16:9 横版出图；提示词用 "the exact same …" 锁定一致性。
   第2/3/4栏必须从头到脚全画幅，鞋履设计（鞋型/鞋面/大底/配色）单独锁死，
   全身镜头强制注入防截断短语 `full length head-to-toe framing, entire shoes completely visible and resting on the studio floor, feet touching ground with soft contact shadow, no cut-off legs, no cropped feet, entire footwear visible`。
3. Character 三视图面部与服装严格一致；服装分层按穿着顺序由内而外；印章用四字短语。
4. 科学数据（拉丁学名、体长、频率、心率等）不确定先查证再写，宁可写区间不编精确值。
5. 大字标题优先保证正确；小字允许图片管线级别的轻微渲染瑕疵，不为此反复重绘超过两次。
6. 模式三要换纸张质感/配色时，从 `references/themes.md` 选预设填入提示词。
7. 底图重塑时严格还原底图主体特征，不凭空捏造。
8. 模式四中文文字禁令：生成阶段的提示词一律加 `no readable text, no letters`，绝不让模型渲染中文；
   所有中文（标题、步骤说明、分量标注、贴士卡）在排版合成阶段用真实中文字体填入。
9. 模式五简笔漫画定调与文字禁令：风格关键词锁死中国学派一系（`golden-age Shanghai Animation Film Studio / Chinese school of animation / hand-drawn cel characters over Chinese ink painting background / opera-inspired patterns / bold folk-art colors`）＋ `ink wash / ink splatter`，
   人物造型另锁简笔动画主角法关键词（见参考文件），基底墨色＋米白留白＋跳色不超两处，不许漂成照片写实、日漫或 3D 味；生成提示词加 `no readable text, no letters, no Chinese characters`，
   仅细节网格允许小号数字编号 01–04；中文标题与标注一律后期合成。
