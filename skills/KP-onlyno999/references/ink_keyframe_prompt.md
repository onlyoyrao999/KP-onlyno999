# 模式五 · 破墨一帧（Ink Keyframe）参考

> 水墨关键帧解构图。2026-10-02 定名「破墨一帧」：破墨是水墨画的真实技法（以墨破水、以淡破浓），
> 一帧破墨 = 把一段视频 / 一张图「破」开，凝住决定性一帧，再解构成图。

## 触发方式（通用流程：一图进 → 成品出）

- 用户只丢**一张图**（照片 / 视频截图 / 剧照 / 底图），并说「水墨风格」（或点名「破墨一帧」），即启动模式五，**不再追问细节**。
- 流程：看图识势（提取主体、动作瞬间、环境、标志性道具与配色锚点）→ 双式构图 → 生成 → 目检 → 交付。
- 默认双出：**电影海报式＋角色动作设计式**各一张；用户点名「展板 / 解构」时另出解构展板式。
- 生成时附用户原图做 `kind: image` 参考，锁主体面部与体型特征，不靠重绘猜脸。

## 识图定势清单（填实前逐项过）

1. 主体：谁 / 什么，外形与服饰锚点（颜色、版型、标志配饰）
2. 势：最有张力的动作瞬间或站位（没有动作的静态图取「立像之势」）
3. 环境：场景骨架（建筑 / 自然 / 道具），哪些元素进环境板、哪些只作背景晕染
4. 跳色锚点：画面里唯一的暖色 / 亮色（如红丝带、朱砂红铠、红绸），全图冷暖对比靠它
5. 细节网格候选：微距受力点、面部神态、质感特写（编织纹 / 甲纹 / 水花 / 地面材质）——凑满 4 格

## 式一 · 电影海报式（Cinematic Keyframe Poster，默认双出之一）

- 单幅电影级关键帧海报，只取全片最具张力的一瞬，按电影海报完成度交付
- 机位优先：极低角度仰拍 / 鸟瞰俯冲 / 对角线下压构图，前景遮挡造纵深
- 张力公式：敌暗我明、势如破竹——主体亮、对手以背影 / 半身压前景
- 氛围件齐活：一束主光、雾气、墨溅边框、纸纹与 film grain

## 式二 · 角色动作设计式（Character Action Design，默认双出之二）

- 同一角色在一张图内排布 4–6 个动态姿态，像动画动作设计稿：起势 → 腾空 → 出招 → 扫腿 / 变招 → 落地收势
- 每姿态锁同一张脸、同一体型、同一套服装；姿态之间用墨迹动线 / 飞白拖影串联动势
- 静态照片无动作时，按人物气质现场设计一套武打动作（马步推掌、凌空飞踢、旋身掌击、低扫腿、抱拳收势）
- 画面不带编号与文字，纯动作设计稿

## 式三 · 解构展板式（Deconstruction Sheet，点名才出）

版式（默认竖版）：

- **左侧 / 上部大主视觉（Hero Action）**：主体最具动态的瞬间或立像，水墨晕染背景，衣袂 / 发带 / 雾气飘逸
- **右上板块（对峙与环境）**：对手 / 环境经典构图，近大远小拉空间纵深
- **右中板块（武器与装备拆解）**：武器细节、头盔 / 道具细节、服饰分层拆解平铺
- **底部一字排开细节网格（Detail Grids 01–04）**：
  - 01 动作受力微距（如竹梢踏枝弯曲）
  - 02 面部神态特写
  - 03 特效定格（水花 / 墨扩散）
  - 04 材质纹理微距（铠甲兽纹 / 编织纹）

## 水墨定调（三式通用，锁死不许漂）

- **基底色**：暗青、墨绿、水墨黑
- **留白**：大面积米白（道袍 / 宣纸底 / 雾气），忌满涂
- **跳色**：仅一至两处——赤红丝带、朱砂红铠甲 / 红绸 / 红对联块面，与墨绿成经典冷暖撞色
- **笔法质感**：赛璐珞手绘（Cel-shaded 2D Animation）＋传统水墨飞白（Ink splatter / flying-white），手绘黑线勾边，纸张颗粒感，轻微 film grain

## 人物定式 · 简笔动画主角法（母本：用户 2026-10-02 提供的参考视频）

从参考片（竹林水泊、白衣侠客 vs 红甲兽面妖将）逐帧拆出的角色画法，以后凡模式五的人物都按这套「主角化」重设计，不是给照片套滤镜：

- **简笔勾线**：黑色轮廓线粗细均匀、笔数极省；五官极简——眉眼一笔带过、鼻梁只一线、嘴一小横，靠脸型和发型认人
- **平涂色块**：服饰大面积平涂，最多一阶阴影，绝不写实渐变；人物是「平」的，背景才是水墨晕染的——平涂人物压水墨景，是这套画法的魂
- **造型概括**：身形与衣纹用少量流畅大线条概括，衣袂 / 飘带拉长线造动势；现代服装保留原图的颜色与款式骨架（T恤还是T恤、长裤还是长裤），只做动画造型法概括，不擅自换装
- **认人锚点**：脸型、体型、发型、标志配色（原图衣服的主色）必须保留，简笔不等于换人
- **气质向主角靠**：站姿挺拔、目光有神、构图给主角位（光打在他身上、对手压暗压前景）
- **可选戏曲化点缀**：用户点名「换装 / 古装」时，才给主角换片中式服饰（素袍＋红腰带＋发髻），反派 / 配角可加兽面纹、靠旗式纹样等戏曲造型元素

## 填实示例（竹林对决视频帧）

- 主体：白衣侠客（素袍、红丝束腰、双短刃）vs 红甲兽面妖将（朱砂红铠、兽角头盔、青竹仗、背竹篓）
- 势：侠客自竹梢俯冲、凌空反身拔刀
- 环境：深幽竹林＋水泊，右上板取「怪将横仗岸边、剑客涉水反手握刀」
- 跳色：红丝带＋朱砂红铠对墨绿竹海
- 细节网格：01 竹梢受力弯曲微距 / 02 英气紧绷面部 / 03 水花定格与墨扩散 / 04 红甲兽纹与背篓编织纹理
- 单帧式（电影海报式）机位：极低角度仰拍，前景高耸竹林，中心侠客踏竹凌空跃下、刀光微亮，下方怪将背影压前景

## 质检清单

1. 主体面部 / 体型与原图一致（附图参考是否生效）；简笔动画主角法到位：简笔勾线、平涂色块、无写实渐变混入；动作设计式逐姿态核对：同一张脸、同一套服装、姿态数量齐
2. 展板式四区齐全：Hero / 环境 / 拆解 / 01–04 细节网格，编号无错位
3. 水墨定调：墨色打底、米白留白、跳色不超两处，无照片写实感混入
4. 画面无乱码文字（编号数字除外）；中文标注已走后期合成
5. 电影海报式：机位张力成立（低角度 / 纵深 / 敌暗我明），不是平铺站桩图；动作设计式：姿态真动态、有动势连贯，不是站姿排队
