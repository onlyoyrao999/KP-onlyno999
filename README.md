## 📖 1. 简介与设计理念 (Design Philosophy)

`KP-onlyno999` 是专为**自然科学科普展板、博物馆物种图鉴、植物学手绘海报与生物信息图表**打造的专业级生成与重塑引擎。

用户提供任意动植物、水生生物、昆虫、花卉或自然摄影底图，系统依托 **Gemini 3.8 多模态视觉模型** 进行形态学、解剖学与生态习性解析，严格按照博物馆级规范自动生成规整、治愈且富有高级感的**九宫格模块化科普信息海报**。

### 🎨 画面风格规范
- **风格定位**: 科普信息海报，写实自然插画风格，高清精细绘制，色彩清新柔和。
- **视觉氛围**: 严谨求实、科普治愈、版式典雅、线条清晰锐利。
- **构图层次**: 
  - **顶部**: 醒目双语大标题、副标题、分类学纲目、诗意导言与右上角地理分布区。
  - **主视觉**: 核心主体生态写实描摹、生态互动（如悬停吸蜜、捕食、翱翔）、手写体金句。
  - **中间区域**: 严格划分的 9 个浅米白圆角信息方框（01至09），带绿色序号与多维图表。
  - **底部**: 生态哲学金句、数据范围标注、连绵青山与草木植被剪影。

## 📐 2. 九宫格标准信息卡片体系 (The 9 Modular Pillars)

海报中央区域严格排布 9 个圆角信息模块（`01` ~ `09`），涵盖生物学与生态学核心维度：

| 模块序号 | 中英模块标题 | 核心科普内容与图表形式 |
| :--- | :--- | :--- |
| **01** | **体型与体重**<br>`SIZE & WEIGHT` | 尺寸与克重跨度，与代表参照物（如蜂鸟 vs 麻雀）进行可视化标尺对比。 |
| **02** | **翅膀结构与悬停飞行**<br>`WING STRUCTURE & HOVERING` | 骨骼解剖图解，标注 180° 肩关节活动度、短宽初级飞羽与微型翼骨枢纽。 |
| **03** | **高速振翅**<br>`HIGH-SPEED WINGBEAT` | 振翅频率（20-80 Hz），8 字形升力闭环气流轨迹与分解动作。 |
| **04** | **长喙与舌部结构**<br>`BILL & TONGUE` | 头部特写与微观解剖，舌尖分叉结构、毛细管自吸效应与特化花冠共生。 |
| **05** | **食物组成与能量占比**<br>`DIET & NUTRITION` | 柱状比例图表（如高糖花蜜 82%、微型昆虫 15%、树汁矿泉 3%）。 |
| **06** | **心率与高代谢**<br>`HEART RATE & METABOLISM` | 极速代谢与生命体征，动态心电波形图（飞行 1250 bpm / 静息 500 bpm / 夜间蛰伏 50 bpm）。 |
| **07** | **迁徙与领地行为**<br>`MIGRATION & TERRITORY` | 3000+ 公里跨洋/跨洲迁徙路线图，体重储脂策略与护花领地巡查。 |
| **08** | **繁殖、巢穴与幼鸟成长**<br>`BREEDING & NESTING` | 1-2 枚微型卵，蛛丝地衣弹性编织巢穴剖面（2-4cm），18-28 天羽化离巢。 |
| **09** | **代表物种与生态价值**<br>`SPECIES & CONSERVATION` | 3 个标志性亚种学名（拉丁双名法）与授粉生态链核心角色。 |

## 🖼️ 3. 底图重塑工作流 (Image-to-Poster Pipeline)

```
[ 用户上传底图 / 摄影 / 草图 ] 
               │
               ▼
[ Gemini 3.8 Multimodal Vision Analysis ]
   ├─ 识别生物物种、纲目科属与拉丁学名
   ├─ 萃取解剖结构、关键运动机制与微观特化
   ├─ 分析食物比例、心率代谢与迁徙路线数据
   └─ 提炼自然哲学金句与色彩基调
               │
               ▼
[ 结构化 JSON Schema 组装 (posterResponseSchema) ]
               │
               ▼
[ React 19 + SVG/Canvas 博物馆级动态排版渲染 ]
   ├─ 典雅浅米 / 复古羊皮纸 / 幽林苔藓 / 黑曜石 / 蓝晒 多主题切换
   ├─ 中英双语 / 纯中文 / 纯英文 排版切换
   └─ 2.5x / 4K 超清 PNG 导出 & 复制完整设计描述词
```

## 🎨 4. 纸张与调色盘预设 (Themes & Palettes)

1. **植物典雅浅米 (`botanical-cream`)**: 象牙浅米白纸感、森系草木绿、暖赭石与鲜艳红花，经典自然历史博物馆风格。
2. **复古牛皮羊皮纸 (`antique-parchment`)**: 沉稳暖褐色、复古墨线手绘、古籍插图质感。
3. **幽林苔藓深绿 (`deep-forest`)**: 墨绿森林基调、苔藓绿与金黄色点缀，夜行生态感。
4. **黑曜石暗夜图鉴 (`obsidian-slate`)**: 极简深黑底色，荧光青与冷白线条，现代标本图谱感。
5. **古典蓝晒印相法 (`cyanotype-blue`)**: 普鲁士蓝与群青印相法，植物学经典标本晒印风格。

```text
具体内容：
- 海报左上角大号标题文字【主标题】，下方英文【Title in English】，副标题文字【副标题】，分类学小字【纲/目/科】。
- 右上角标题文字【分布：生境区 / Distribution】，地图图例标注主要分布、次要分布与零星分布。
- 画面上方主视觉：主体动态悬停/特写，生态交互细节，手写体小字【金句】。
- 画面分割成九个圆角浅米白色信息方框（01至09），带绿色序号、中英标题与精准科学数据。
- 海报底部左侧文字【生态哲学金句】，右下角【数据范围说明与年份更新】，背景铺有淡淡的虚化植被纹理与连绵青山。

构图方式：竖版海报网格模块化构图，九宫格信息板块排布，视觉层次从上至下依次为标题主视觉、科普模块、底部风景。
```

- **开发指令**:

  ```bash
  npm run dev   # 启动全栈开发服务 (端口 3000)
  npm run build # 生产环境打包
  ```
