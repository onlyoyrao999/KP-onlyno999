## 🚀 1. 三模态智能自适应切换体系 (Tri-Engine Pipeline)

```
                       ┌─► [服装单品/模特上身图] ──► 【模式一：电商模特四联打版图】(Lookbook Tetradic Sheet)
[ 上传底图 / 提示词 ] ──┼─► [人物肖像/古风二次元] ──► 【模式二：角色概念与服饰解构】(Character Design Sheet)
                       └─► [动植物/昆虫/自然摄影] ──► 【模式三：自然科学九宫格图鉴】(Naturalist Infographic)
```

## 👔 2. 模式一：电商模特拍摄规范图 (E-commerce Lookbook)

- **版式结构：四联分栏式拼图 (1:1:1:1 绝对规整纵向分割)**：
  - **Column 01（大头照特写）**：展示面部轮廓、帽子帽檐弧度、T恤圆领高度与锁骨贴合度。
  - **Column 02（正面全身/半身）**：展示衣服正面版型、落肩袖宽、裤子口袋、整体穿搭比例。
  - **Column 03（90°侧面全身）**：展示袖长、帽子侧面深度、裤侧立体工装口袋厚度、鞋身侧线。
  - **Column 04（背面全身）**：展示肩线平整度、无多余褶皱、后腰口袋与后背版型。
- **模特与服装标准化**：中性自然克制表情，真实还原纯棉/斜纹/尼龙面料质感。
- **影棚级一致性光影**：5500K 柔光箱双侧布光，纯浅灰白背景（`#e6e8ec`），85mm 人像定焦零透视畸变。
- **深灰标签系统**：每栏下方配置深灰色标示条。

## 🎭 3. 模式二：角色概念设定集 (Character Design Sheet)

- **三视图主立绘**：大比例动态主立绘（持琴/御剑/持刃） + 侧面/背面中立立姿。
- **服装分层解构**：6 层服装穿着顺序平铺（内衽、中单、腰封、大袍、披帛、马面裙）。
- **1x5 材质微距矩阵**：金丝刺绣、提花罗织、蝉翼生纱、羊脂白玉、云头靴履。
- **美术包装**：宣纸留白、淡墨竹影、书法排版、朱砂印章。

## 🌺 4. 模式三：自然科学九宫格科普图鉴 (Naturalist Infographic)

- 顶部双语大标题 + 美洲/全球地理分布热力图。
- 蜂鸟/蝶/鲸主视觉悬停写实插画 + 生态互动。
- 01-09 九大科学维度卡片（尺寸标尺、解剖、振翅频率、长喙微观、食物比例、心率心电图、迁徙航线、巢穴繁育、代表物种）。
- 底部连绵青山剪影与生态哲学金句。
